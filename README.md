<img src="./tecleoCSS.gif" width="400" height="396"/>

## Qué es

Animación de escritura estilo teclado digital sobre una ilustración conceptual de un corazon plastificado (hecha por mi). La animación se encuentra en loop desde el css: el cursor va mostrando la texto letra por letra, al terminar de escribir las borra una por una  y se vuelve a repetir el ciclo de escritura.
